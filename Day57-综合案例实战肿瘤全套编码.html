🗺️ 一、肿瘤编码全景地图（诊断篇）

肿瘤编码的「总坐标系」是部位码 + 形态学码双轨并行。部位码决定「长在哪」，形态学码决定「长成什么样、良性恶性」。先看部位码的四大分区：

分区码位范围含义编码特点
恶性肿瘤（原发）C00-C97浸润性恶性肿瘤主诊断的核心区，绝大多数实体瘤落在这里
原位癌D00-D09未突破基底膜的癌「癌」但不是 C 章，动态码是 /2
良性肿瘤D10-D36良性新生物动态码 /0
动态未定 / 未知D37-D48交界性、性质待定动态码 /1 或 /9
🧭 高频部位码速查：C16 胃 · C18 结肠 · C20 直肠 · C22 肝 · C25 胰腺 · C34 肺 · C50 乳腺 · C53 宫颈 · C56 卵巢 · C61 前列腺 · C64 肾 · C67 膀胱 · C71 脑 · C73 甲状腺 · C81-C96 淋巴造血 · C90 多发性骨髓瘤 · C91-C95 白血病 · C97 复合性恶性肿瘤 · C80 未特指部位（仅原发灶不明时用）。

部位码之外，还有一条「转移轨道」：C77-C79 专门用来表达继发（转移）性肿瘤——C77 淋巴结转移、C78 呼吸和消化器官转移、C79 其他部位转移。当住院是治疗转移灶时，主诊断就落在这些码上。

🧬 二、双编码铁律：部位码 + 形态学码（M 编码）

ICD-10 对肿瘤采用双编码：一个部位码（说明解剖位置），一个形态学码 M（说明组织学类型和良恶性）。部位码是主码，形态学码是附加码——只有拿到了病理报告，才编 M 形态学码。

2.1 形态学动态码——五档一字定生死

M 编码斜杠后第 1 位的「动态码」是肿瘤编码的核心：

动态码含义对应部位码分区示例
/0良性D10-D36M8850/0 脂肪瘤
/1动态未定（交界性）D37-D48M8442/1 交界性卵巢浆液性肿瘤
/2原位癌D00-D09M8500/2 导管原位癌（DCIS）
/3恶性，原发C00-C97M8140/3 腺癌
/6恶性，转移性/继发C77-C79M8140/6 转移性腺癌
/9恶性，未特指C 章M8010/9 癌，未特指
⚠️ 铁律一：形态学动态码必须和部位码对得上。原位癌（/2）绝不能编到 C 章（C 章是浸润性恶性 /3）。病理写「导管原位癌」→ 部位 D05（乳腺原位癌）+ M8500/2，而不是 C50。
⚠️ 铁律二：淋巴造血系统肿瘤（白血病 C91-C95、淋巴瘤 C81-C85、多发性骨髓瘤 C90）不额外编 M 形态学码——因为 C 章这些类目本身已经按组织学分类好了。避免画蛇添足。

🎯 三、肿瘤主诊断选择：九条规则（实战精简版）

肿瘤主诊断选择的本质，是回答一个问题：这次住院到底「主要为了什么」？围绕住院目的，九条规则可以浓缩成一张决策表：

住院目的主诊断肿瘤本身说明
首次确诊 / 治疗原发肿瘤肿瘤部位码主诊断例：C34 肺癌，本次行根治术
单纯放疗Z51.0其他诊断放疗疗程为主诊断
单纯化疗 / 靶向 / 免疫Z51.1（化疗）/ Z51.2（其他）其他诊断化疗为主诊断
确诊 + 同次化疗肿瘤部位码主诊断首次确诊并入化疗，肿瘤做主诊断
复查 / 随诊Z08其他诊断恶性肿瘤治疗后随诊
肿瘤并发症为主并发症码其他诊断如贫血、肠梗阻、感染
治疗转移灶转移部位码（C77-C79）原发灶其他诊断如 C79.5 骨转移
临终 / 死亡肿瘤部位码主诊断死于肿瘤本身
预防性手术（高危）Z40.0—如 BRCA 突变预防性乳腺切除
⚠️ 最容易错的两种：
① 单纯化疗：主诊断是 Z51.1（不是肿瘤码），但肿瘤码仍要编为其他诊断（否则医保清单信息缺失）。
② 确诊 + 同次化疗：本次首次确诊肿瘤并同步化疗，主诊断是肿瘤本身（不是 Z51.1），这是唯一一个「化疗但主诊断仍是肿瘤」的特例。

💊 四、放化疗 Z 码与随诊 Z08：主诊断切换逻辑

❌ 常见错误：化疗住院把肿瘤做主诊断

「肺癌」入院化疗，主诊断编 C34.9。

错在：本次住院主要治疗是「化疗」，不是肿瘤本身的手术/根治。主诊断应为 Z51.1，C34.9 降为其他诊断。

✅ 正确：化疗为主诊断 Z51.1

主诊断 Z51.1（肿瘤化学治疗疗程）；

其他诊断 C34.9（肺癌）+ M8041/3（小细胞癌，若有病理）。

4.1 Z 码放化疗家族

编码含义
Z51.0放射治疗疗程
Z51.1化学治疗疗程（含靶向、内分泌治疗的疗程编码场景需核对）
Z51.2其他特指的治疗后医疗照护（免疫治疗等按实际核对）

🔪 五、肿瘤手术编码：根治术多码组合

肿瘤根治术从来不是「一个码」，而是「部位切除 + 淋巴结清扫 + 术式/范围附加」的一串码。核心原则：切除范围决定主码，淋巴结清扫必须另编。

5.1 常见根治术多码组合

术式主码（部位切除）附加码（淋巴结清扫等）
胃癌根治术43.5-43.9（胃部分/全切除）40.59 区域淋巴结清扫
结肠癌根治术45.7x（结肠部分切除）40.59 区域淋巴结清扫
直肠癌根治术（Miles）48.5/48.6（腹会阴联合切除等）40.59 + 可能造口 46.1x
肺癌根治术32.4（肺叶切除）40.59 淋巴结清扫（纵隔）
乳腺癌改良根治术85.43（改良根治）40.3 区域淋巴结清扫（腋窝）
宫颈癌根治术68.6/68.7（子宫根治性切除）40.59 盆腔淋巴结清扫
🔑 淋巴结清扫码：颈/腋窝/腹股沟等表浅淋巴结清扫多用 40.3（区域淋巴结清扫）；胸腔/腹腔/盆腔等深部淋巴结清扫多用 40.59（其他淋巴结根治性清扫）。看手术记录写的清扫范围。
⚠️ 避坑：「根治术」三个字不能直接当主码查。先拆出实际切除的器官和范围（胃切了多少？肺切了几叶？），再分别编码。「全胃切除根治术」= 43.99 全胃切除 + 40.59，而不是一个「根治术码」。

💡 六、重难点深度解析：动态码「一字之差」的编码事故

今天最高频、后果最严重的错误，是形态学动态码选错。同样是乳腺肿块，病理报告用词的细微差别，会导向完全不同的编码：

「乳腺导管原位癌 DCIS」

动态码 /2 → 部位 D05.1 + M8500/2。

原位癌，不编 C50。

「乳腺浸润性导管癌」

动态码 /3 → 部位 C50.9 + M8500/3。

浸润性恶性，编 C 章。

「卵巢交界性浆液性肿瘤」

动态码 /1 → 部位 D39.1 + M8442/1。

动态未定，不编 C 章。

「肝转移性腺癌（原发结肠）」

转移灶动态 /6 → 部位 C78.7（肝继发）+ 原发 C18.9 其他诊断。

主诊断是转移灶（若本次治转移）。

⚠️ 三条铁律（务必背下）：
① 动态码决定分区——/2 一定落 D00-D09（原位），/3 才落 C 章（恶性原发），/1 落 D37-D48（交界）。
② 没有病理不编 M——临床只写「占位/肿物」而无病理，部位码按动态未定 D37-D48 或临床判断处理，不硬套 /3。
③ 转移灶 ≠ 原发灶——原发已确定时，转移灶编 C77-C79（动态 /6），原发部位另列其他诊断。
💡 编码员动作：拿到肿瘤病历，先翻病理报告——这是形态学码的唯一依据。病理写「浸润」「癌（Carcinoma）」→ /3；写「原位」「上皮内瘤变 III 级」→ /2；写「交界性」→ /1。病理没出，别急着编 M 码。

基础题 · 双编码（部位 + 形态学） PRACTICE

女，58 岁，胃镜活检病理：「胃窦腺癌」。住院行胃癌根治术（胃大部切除 + 区域淋巴结清扫）。

问题：给出诊断编码（部位 + 形态学）与手术编码。

点击查看答案

✅ 诊断编码：部位 C16.3（胃窦恶性肿瘤）+ 形态学 M8140/3（腺癌）。

✅ 手术编码：43.7（胃部分切除，胃大部）+ 40.59（区域淋巴结清扫）。

推理：部位 + 形态学双编码缺一不可；根治术拆成「胃切除 + 淋巴结清扫」两码。

💡 避坑：别漏编 M8140/3。只有病理确诊的腺癌才补形态学码。

2
基础题 · 原位癌 vs 浸润癌 PRACTICE

女，45 岁，乳腺钼靶提示「右乳导管原位癌（DCIS）」，行保乳手术 + 前哨淋巴结活检。

问题：诊断编码？

点击查看答案

✅ 诊断编码：部位 D05.1（乳腺导管原位癌）+ 形态学 M8500/2（导管原位癌）。

推理：「原位癌」动态码 /2 → 编 D00-D09 原位癌区，不编 C50（那是浸润性）。

💡 避坑：「原位癌」三个字就是分水岭。看到 DCIS / CIS / 上皮内瘤变 III 级，都走 D 章。

3
基础题 · 化疗住院主诊断 PRACTICE

男，62 岁，确诊「右肺小细胞癌」1 月，本次入院行第 2 周期化疗。

问题：主诊断选什么？

点击查看答案

✅ 主诊断：Z51.1（肿瘤化学治疗疗程）。

✅ 其他诊断：C34.9（肺恶性肿瘤）+ M8041/3（小细胞癌）。

推理：本次住院主要目的是「化疗」，不是首次确诊也不是手术，故主诊断 Z51.1；肿瘤码降为其他诊断。

💡 避坑：若本次是「首次确诊 + 同次化疗」，主诊断才是肿瘤本身，这是唯一特例。

4
进阶题 · 转移灶 vs 原发灶主诊断 CHALLENGE

男，70 岁，结肠癌术后 2 年，本次因「腰背痛」入院，PET-CT 示「腰椎骨转移」，行腰椎转移灶放疗。

问题：主诊断选什么？结肠癌怎么编？

点击查看答案

✅ 主诊断：C79.5（骨继发性恶性肿瘤）——本次主要治疗的是腰椎骨转移灶。

✅ 其他诊断：C18.9（结肠恶性肿瘤，原发灶）+ Z85.0（消化器官恶性肿瘤个人史，若已治愈）。

推理：治疗靶点是「转移灶」而非原发灶，故主诊断落在 C79（继发恶性肿瘤）；原发结肠癌作其他诊断。

💡 避坑：别把原发结肠癌 C18 当主诊断——本次没在治它。主诊断必须匹配本次治疗。

5
进阶题 · 交界性肿瘤动态码 CHALLENGE

女，33 岁，术中冰冻 + 术后病理：「左侧卵巢交界性浆液性肿瘤」，行左侧附件切除术。

问题：诊断编码？

点击查看答案

✅ 诊断编码：部位 D39.1（卵巢动态未定肿瘤）+ 形态学 M8442/1（交界性浆液性肿瘤）。

推理：「交界性」= 动态码 /1 → 编 D37-D48 动态未定区，不编 C56（恶性）。

💡 避坑：交界性肿瘤不是「恶性」，也不是「良性」，是 /1 独立档位。编错到 C56 属于高套。

6
进阶题 · 完整综合病例（双编码 + 主诊断 + 根治术） CHALLENGE

男，66 岁，因「大便带血 3 月」入院，肠镜活检病理：「直肠腺癌」。行「直肠癌根治术（腹会阴联合切除术）+ 盆腔淋巴结清扫 + 乙状结肠造口术」。

问题：给出① 主诊断 ② 形态学码 ③ 完整手术编码 ④ DRG 入组思路。

点击查看答案

✅ ① 主诊断：C20（直肠恶性肿瘤）——本次首次确诊并手术治疗，主诊断是肿瘤本身。

✅ ② 形态学码：M8140/3（腺癌）。

✅ ③ 手术编码：48.5（腹会阴联合切除术）+ 40.59（盆腔淋巴结清扫）+ 46.11（结肠造口术）。

✅ ④ DRG 思路：主诊断 C20（直肠癌）+ 根治手术 → 入 MDCG「消化系统疾病」的手术组；腹会阴联合切除属大手术，权重高。

💡 核心教训：这一题串起「双编码（C20 + M8140/3）→ 主诊断（肿瘤本身）→ 根治术多码（切除 + 清扫 + 造口）→ DRG」完整链条，是肿瘤病案编码的标准动作。
