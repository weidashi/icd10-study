🏥 DRG 分组原理：MDC → ADRG → DRG

医保支付改革下的编码应用 —— 第五阶段开篇

进度 46 / 60 天（76.7%）

📖 一、DRG 是什么？

1.1 定义：诊断相关分组

DRG（Diagnosis Related Groups，诊断相关分组）是一种将住院患者按照疾病诊断、治疗方式、年龄、合并症与并发症等因素进行归组的分类体系。其核心假设是：分到同一组的患者，诊疗路径相近、医疗资源消耗（费用与住院天数）相近，因此可以为每组设置一个统一的权重和付费标准。

1.2 核心逻辑：从「无数病案」到「有限组别」

DRG 的本质是把成千上万种病案归并到几百个组。全国每年数亿住院病案，通过「分组器（Grouper）」自动映射到有限数量的 DRG 组，每个组对应一个权重（RW，Relative Weight）和付费标准。医保按「组」向医院付费，取代过去的按「项目」逐项付费——这就是 DRG 付费（按疾病诊断相关分组付费）的根基。

💡 核心认识：在 DRG 付费体系里，病案首页的诊断与手术编码是分组器的唯一输入。分组器读不到病历正文、看不见临床思维，它只读首页编码。因此——编码质量直接决定入组，入组直接决定付费。这是整个第五阶段最需要印在脑子里的一句话。

🗺️ 二、DRG 三层分组结构（核心）

DRG 分组不是一步到位的，而是经过「MDC → ADRG → DRG」三层递进：从大系统归类，到核心组归类，再到最终细分组。

1

MDC（Major Diagnostic Category）主要诊断大类 —— 第一层

按主要诊断的解剖系统 / 疾病系统划分，共 26 个 MDC。如 MDCA 神经系统、MDCB 眼、MDCC 耳鼻喉、MDCD 口腔颌面、MDCE 呼吸系统、MDCG 消化系统……MDCZ 其他。

规则：先看主要诊断属于哪个系统 → 确定 MDC。这一步错了，后面全部错。

2

ADRG（Adjacent DRG）核心疾病诊断相关分组 —— 第二层

在每个 MDC 内部，再按「主要诊断 + 主要手术/操作」进一步细分，形成 ADRG。ADRG 大致分三类：手术组 / 操作组 / 内科组（保守治疗组）。全国 ADRG 约 300-400 个。

规则：做了手术走手术组，只做了介入/内镜等操作走操作组，纯保守治疗走内科组。

3

DRG 最终组 —— 第三层

在 ADRG 内部，再按有无并发症与合并症（CC）及其严重程度（MCC）细分为最终的 DRG 组：无 CC 组 / 有 CC 组 / 严重 CC（MCC）组。

规则：合并症越严重 → 分组越靠后 → 权重越高 → 医保支付越多。这是编码中「含金量」最高的地方。

🏛️ 三、CHS-DRG 分组体系

3.1 什么是 CHS-DRG

CHS-DRG（CHS = China Healthcare Security，国家医疗保障疾病诊断相关分组）是国家医保局主导制定的全国统一版本，用于全国医保 DRG 付费试点。它是目前国内 DRG 付费落地执行的标准分组方案，编码员日常面对的就是这套分组逻辑。

3.2 分组要素（分组器读了哪些信息）

分组要素在分组中的作用
主要诊断决定进入哪个 MDC —— 最核心的入口要素
其他诊断（并发症合并症）决定是否有 CC / MCC —— 影响最终 DRG 细分
主要手术操作决定进入哪个 ADRG（手术组 / 操作组 / 内科组）
性别、年龄少数病种的辅助判别（如产科、新生儿）
离院方式死亡、转院等异常离院可能触发特殊校验
住院天数异常值（过短 / 过长）参与入组校验

3.3 并发症与合并症等级（CC / MCC）

1

无 CC 组

患者无并发症合并症，或合并症不属于 CC 表所列范围 → 归入基础 DRG 组，权重最低。

2

有 CC 组

存在列入「并发症合并症对照表（CC 表）」的疾病 → 归入有 CC 组，权重提高一档。

3

严重 CC 组（MCC）

存在列入「严重并发症合并症对照表（MCC 表）」的疾病 → 归入 MCC 组，权重最高。

注意：MCC 并非所有疾病都够格，必须落在 MCC 表内的特定编码上才计。

⚠️ 关键提示：「有 CC」还是「无 CC」，取决于该合并症编码是否在官方 CC/MCC 表中，而不是临床认为的严重程度。同一诊断在不同 ADRG 里，可能一个算 CC、另一个不算。编码员必须熟悉常见 CC/MCC 表内诊断，才能不漏填、不误判。

🔀 四、DRG 分组流程（4 步）

把一份病案放进分组器，实际经历的流程如下：

1

第一步：按主要诊断归入 MDC

分组器读取首页主要诊断编码，按解剖/疾病系统归入 26 个 MDC 之一。主要诊断必须与本次住院的主要诊疗目的一致。

2

第二步：按主要手术/操作或内科治疗方式归入 ADRG

看首页主要手术操作编码：有手术 → 手术组；有非手术操作（介入、内镜等）→ 操作组；无手术操作 → 内科组。据此确定 ADRG。

3

第三步：按并发症合并症（CC / MCC）细分 DRG

扫描首页全部其他诊断，判断是否存在 CC 或 MCC，将 ADRG 细分到最终 DRG 组（无CC / 有CC / MCC）。

4

第四步：校验权重 / 费率，确定付费

确定 DRG 组后，按组内权重（RW）与地区费率计算出应支付金额，并校验病案数据的逻辑一致性（如歧义校验、低码高编检查）。

⚡ 五、编码对 DRG 的影响（重点）

DRG 付费下，编码不再是「记病历」的附属工作，而是直接决定医院收入的环节。下面五个影响点必须逐条吃透：

编码问题后果影响层级严重性
主要诊断选错 整个 MDC 都错，入到别的系统组 第一层 MDC 致命性错误
手术编码漏填 / 错填 ADRG 判断错误（手术组 → 错入内科组） 第二层 ADRG 高影响
并发症合并症漏填 无法分到 CC / MCC 组 → 权重偏低、付费减少 第三层 DRG 经济损失
诊断与手术不匹配（QY 歧义病例） 无法入组，按协商支付/亏损处理 全流程 直接亏损
虚增诊断、高套编码 套取高权重组 → 医保飞检重点对象，面临追回+处罚 合规风险 法律风险
⚠️ 歧义病例（QY，Questionable）：当主要诊断与主要手术操作不匹配时，分组器无法确定入组，这类病案被称为歧义病例。例如诊断为「急性阑尾炎」却行了「胆囊切除术」——诊断和手术对不上，无法归组。歧义病例通常按较低标准支付甚至不支付，是医院亏损的重要来源，需要编码员主动发现并与临床沟通修正。
🚨 「高套」风险（编码高编 / 低码高编）：为了套取更高权重组，虚增并发症合并症、把主要诊断升级为更「值钱」的疾病、或把低难度病案编成高难度手术。这类行为是国家医保飞行检查的重点打击对象。编码员必须守住底线：只编码有客观病历依据的内容。

概念含义举例

✏️ 七、今日案例练习（共 4 题）

前2题为基础题（分组路径推导），后2题为进阶题（权重与入组判断）。点击答案查看推理过程。

1
基础题 · 内科病案分组路径推导 PRACTICE

患者，男，45 岁，因肺炎（J18.9）入院，无手术、无操作、无并发症合并症，抗感染保守治疗后出院。

问题：请按「MDC → ADRG → DRG」三层结构推导该病案的分组路径。

点击查看答案

✅ 第一步 · MDC：主要诊断肺炎（J18.9）属于呼吸系统疾病 → 归入 MDC 呼吸系统大类。

✅ 第二步 · ADRG：首页无手术、无介入/内镜等操作，仅保守抗感染治疗 → 归入 ADRG 呼吸系统内科组（非手术组）。

✅ 第三步 · DRG：患者无任何并发症合并症 → 细分到 DRG 无CC组。

最终入组：呼吸系统内科无合并症并发症组（权重相对较低）。

💡 启示：同样的肺炎，如果患者合并了糖尿病（CC），就会升入「有CC组」，权重和付费随之提高——这就是其他诊断编码的价值所在。

2
基础题 · 手术病案分组路径推导 PRACTICE

患者，女，68 岁，因股骨头坏死（M87.0）行全髋关节置换术（81.51），无并发症合并症。

问题：请推导分组路径，并说明若漏填手术编码会怎样。

点击查看答案

✅ 第一步 · MDC：股骨头坏死（M87.0）属于肌肉骨骼系统 → 归入 MDC 肌肉骨骼系统大类。

✅ 第二步 · ADRG：本次住院行了主要手术全髋关节置换（81.51）→ 归入 ADRG 髋关节置换手术组（手术组）。

✅ 第三步 · DRG：无并发症合并症 → DRG 无CC组。

⚠️ 若漏填手术编码：分组器看不到 81.51，会把病案归入 肌肉骨骼内科组（保守治疗组）——髋关节置换的手术费、材料费全部无法通过 DRG 体现，权重和付费断崖式下降，造成严重亏损。

💡 启示：主要手术操作编码是 ADRG 分组的决定性输入，漏填 = 入错组 = 亏损。

3
进阶题 · MCC 对入组差异的影响 CHALLENGE

两位急性心肌梗死（I21.9）患者均行经皮冠状动脉介入治疗（PCI）。患者 A 入院时伴严重心力衰竭；患者 B 无任何合并症。

问题：两人入组有何差异？为什么「严重心衰」能显著改变入组结果？

点击查看答案

✅ 分组差异：

  • 患者 B（无心衰）→ 心梗PCI无CC组，权重相对较低
  • 患者 A（严重心衰）→ 心梗PCI伴MCC组，权重最高一档

✅ 为什么能改变入组：严重心力衰竭属于严重并发症合并症（MCC），列入 MCC 对照表。分组器在第三步扫描其他诊断时识别到 MCC → 在 ADRG 内细分到最重的一档 → 权重显著上浮。

💡 关键点：心衰是否被识别为 MCC，前提是首页其他诊断里必须准确填了心衰编码（如 I50.x）。如果临床诊断了心衰但编码员漏填，患者 A 就会按「无CC组」支付——权重白白损失。

→ 结论：MCC 组权重更高，但「能不能进 MCC 组」完全取决于其他诊断编码是否完整准确。

4
进阶题 · 歧义病例（QY）识别 CHALLENGE

病案首页显示：主要诊断为「急性阑尾炎」，主要手术为「胆囊切除术」，无其他诊断。

问题：① 分组器会如何处理？② 编码员应该怎么做？

点击查看答案

✅ ① 分组器处理：主要诊断（阑尾炎）与主要手术（胆囊切除）在逻辑上完全不匹配——阑尾炎的标准术式是阑尾切除术，胆囊切除术针对的是胆囊疾病。分组器无法确定入组，判定为歧义病例（QY），无法进入正常 DRG 组。

✅ ② 编码员应做：

  1. 回查病历：核对手术记录、出院诊断，判断哪个诊断/手术填写有误
  2. 与临床沟通：是阑尾炎诊断错了（实为胆囊炎），还是手术填错了（实为阑尾切除术）？
  3. 修正后重新编码：让诊断与手术恢复逻辑一致性，再提交分组

⚠️ 后果提示：QY 病例不能入组，通常按最低标准或不支付处理，是医院直接的经济损失。编码员是发现 QY 的第一道防线。

🆚 八、易错点对比（正确 vs 错误）

✅ 正确：主诊断写「病因 + 具体诊断」

如「2型糖尿病伴糖尿病足坏疽」——直接对应内分泌系统 MDC 与对应 DRG 组

病因明确，入组准确

❌ 错误：主诊断只写症状

如只写「下肢坏疽」（症状/表现）而不写糖尿病（病因）→ 入错 MDC（从内分泌系统错入循环系统）

症状是表现的编码，病因才是分组的核心

✅ 正确：完整填写其他诊断

临床明确诊断的合并症（糖尿病、高血压、心衰等）全部填入其他诊断 → 正确计入 CC/MCC

权重充分体现资源消耗

❌ 错误：并发症合并症漏填

病历里明确有合并症，但首页其他诊断没填 → 分不到 CC/MCC 组 → 权重偏低、付费减少

「漏填=亏损」，是权重损失最常见原因

✅ 正确：手术操作编码完整准确

手术/操作与主要诊断匹配，手术组 ADRG 入组正确，费用充分体现

手术组权重远高于内科组

❌ 错误：手术编码漏填

做了手术但首页漏填手术编码 → 分组器按内科组处理 → 权重断崖下跌

手术漏填 = 手术组变内科组

✅ 正确：只编有客观依据的诊断

编码以病历记录、检查检验结果为唯一依据，实事求是

合规安全，经得起飞检

❌ 错误：高套诊断套高权重组

虚增合并症、升级主要诊断，把病案「编重」套取高权重组

医保飞检重点打击，追回费用+行政处罚+信用受损

✅ 九、今日重点回顾

三层分组：MDC（系统）→ ADRG（治疗方式）→ DRG（合并症轻重）
主要诊断定 MDC：主诊断选错，整个系统都入错
手术操作定 ADRG：手术组 / 操作组 / 内科组，漏填=入错组
CC/MCC 定最终 DRG：无CC → 有CC → MCC，权重逐档上升
合并症漏填=亏损：其他诊断编码直接决定能否进 CC/MCC 组
QY 歧义病例：诊断与手术不匹配无法入组，需回查病历沟通修正
高套诊断=飞检风险：只编有客观病历依据的诊断，守住合规底线
编码=付费唯一输入：首页编码质量直接决定入组与医保结算
